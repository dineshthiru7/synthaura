Technical Documentation for AI Voice Backend

1. Configuration (app/config.py)

Purpose

The configuration module manages all application settings and environment variables in a type-safe manner using Pydantic's BaseSettings.

Key Components

  • Settings Class: Defines all configuration parameters with type hints and default values

  • Environment Variables: Loads from .env file automatically

  • Type Validation: Ensures all configurations are properly typed

Configuration Parameters

Parameter Type Default Description
PROJECT_NAME str "AI Voice Backend" Application name
API_V1_STR str "/api/v1" API version prefix
OPENAI_API_KEY str - Required OpenAI API key
DEEPSEEK_API_KEY str - Required DeepSeek API key
DEEPSEEK_API_URL str DeepSeek endpoint DeepSeek API URL
DATABASE_URL AnyUrl PostgreSQL URL Database connection string
LOG_LEVEL str "INFO" Logging level
CORS_ORIGINS list ["*"] Allowed CORS origins

Usage

python
Copy
from app.config import settings

# Access configuration
db_url = settings.DATABASE_URL

2. Main Application (app/main.py)

Purpose

The main application file initializes the FastAPI application and sets up core middleware and routes.

Key Components

  • FastAPI Instance: Creates the main application with metadata

  • CORS Middleware: Configures Cross-Origin Resource Sharing

  • Logging Setup: Initializes application logging

  • Router Inclusion: Mounts all API routers

  • Lifecycle Events: Startup/shutdown event handlers

Initialization Flow

  1. Create FastAPI app with metadata

  2. Configure CORS middleware

  3. Set up logging

  4. Include routers (health, chat)

  5. Add startup/shutdown event handlers

Example Usage

python
Copy
# Run with: uvicorn app.main:app --reload

3. Chat Router (app/routers/chat.py)

Purpose

Handles all chat-related API endpoints, including processing voice transcripts and returning AI responses.

Key Components

  • APIRouter: FastAPI router for chat endpoints

  • OAuth2 Security: Token-based authentication

  • Request/Response Models: Type-safe data models

  • Error Handling: Proper HTTP exception handling

Endpoints

Method Path Description
POST /chat Process voice transcript and get AI responses

Dependencies

  • Token validation

  • ChatService injection

Example Request

json
Copy
{
  "message": "Hello AI",
  "services": ["chatgpt", "deepseek"]
}

4. Chat Service (app/services/chat_service.py)

Purpose

Orchestrates communication between the API and AI services (OpenAI, DeepSeek).

Key Components

  • Service Composition: Combines OpenAI and DeepSeek services

  • Async Processing: Concurrent API calls to AI services

  • Error Handling: Graceful degradation if services fail

  • Logging: Detailed error logging

Methods

Method Description
process_request Main entry point for chat processing
_get_openai_response Gets response from OpenAI
_get_deepseek_response Gets response from DeepSeek

Flow

  1. Validate request

  2. Start concurrent tasks for selected services

  3. Gather responses

  4. Format results

  5. Handle errors gracefully

5. OpenAI Service (app/services/openai_service.py)

Purpose

Encapsulates all interactions with the OpenAI API.

Key Components

  • Async Client: Uses OpenAI's async API

  • Configuration: Loads API key from settings

  • Error Handling: Logs and propagates errors

  • Response Processing: Extracts relevant response data

Methods

Method Description
get_chat_response Gets chat completion from GPT-3.5

Configuration

  • Model: gpt-3.5-turbo

  • Temperature: 0.7

  • Max Tokens: 1000

6. DeepSeek Service (app/services/deepseek_service.py)

Purpose

Handles all interactions with the DeepSeek AI API.

Key Components

  • Async HTTP Client: Uses httpx for async requests

  • Configuration: Loads API key and URL from settings

  • Error Handling: Logs and propagates errors

  • Response Processing: Extracts relevant response data

Methods

Method Description
get_chat_response Gets chat completion from DeepSeek

Configuration

  • Model: deepseek-chat

  • Temperature: 0.7

  • Max Tokens: 1000

  • Timeout: 30 seconds

7. Dockerfile

Purpose

Defines the container image for the application.

Key Components

  • Base Image: Python 3.9-slim

  • System Dependencies: build-essential, libpq-dev

  • Python Dependencies: Installed from requirements.txt

  • Environment Variables: PYTHONPATH, PYTHONUNBUFFERED

  • Startup Command: Runs migrations and starts Uvicorn

Build Process

  1. Install system dependencies

  2. Copy and install Python requirements

  3. Copy application code

  4. Set environment variables

  5. Define startup command

Usage

bash
Copy
